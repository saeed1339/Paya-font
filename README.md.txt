# Paya Font

Paya is a Persian/Arabic typeface family in 5 weights (Thin, Light, Regular, Medium, Bold), based on the DejaVu Fonts and Vazir template. All Persian glyphs have been completely redesigned by Saeed Rezaee.

## Features
- Supports Persian, Arabic, and Latin scripts.
- 5 weights: Thin, Light, Regular, Medium, Bold.
- OpenType features including proper mark positioning and shaping for Arabic script.

## Building

Fonts are built automatically using GitHub Actions. You can also build them manually:

1. Install requirements: `pip install -r requirements.txt`
2. Build fonts: `make build`
3. Run tests: `make test`
4. Generate proof files: `make proof`
